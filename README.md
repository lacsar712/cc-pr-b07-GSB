# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

连续套不准会触发自动缓领：印刷员在「缓领策略」页设定连续失败阈值与缓领秒数。领取进程发现最近已出结论里连续套不准达到阈值，就暂停领取普通任务若干秒（急件仍可领取），到期自动恢复。缓领开始、结束与策略调整都写入流水，可在策略页查看。

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮，也不能修改缓领策略。
4. 顶栏进入「缓领策略」，把连续失败阈值设成 2、缓领秒数设成 8。
5. 连续送两笔青偏差 0.5、必套不准的样张：第二笔出结论后队列页出现缓领横幅，再送普通任务会停在待处理，送急件（勾选「急件」）仍能立即领取出结论。
6. 8 秒后缓领结束，普通任务恢复领取；策略页流水里依次有「策略更新」「缓领开始」「缓领结束」三条记录。
