# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

最近已出结论里连续套不准达到阈值时，领取进程自动进入缓领：普通任务暂停领取若干秒，急件照常。缓领的开始与结束都会写入流水。顶栏「缓领策略」页可设连续失败阈值与缓领秒数，并查看缓领流水。


## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 顶栏打开「缓领策略」，把连续失败阈值设为 2、缓领秒数设为 30 并保存。
5. 连续送两笔青偏差 0.5 的印张，两笔都出套不准后，普通队列进入缓领：队列页出现缓领提示，普通任务停在待处理，急件仍可领；缓领流水里出现开始与结束记录。
